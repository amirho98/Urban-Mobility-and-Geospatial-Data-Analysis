# Urban Mobility and Geospatial Data Analysis

## Project Overview

An academic data science project conducted at Politecnico di Torino, focusing on the spatial, temporal, and operational analysis of shared e-scooter services in Turin, Italy.

The study examines approximately 2.64 million cleaned trip records from three major mobility operators: Lime, Bird, and Voi.

## Project Objectives

- Large-scale mobility data processing and cleaning
- Machine learning-based anomaly detection
- Geospatial and spatiotemporal analysis
- Origin-Destination (OD) matrix generation
- Urban travel demand and mobility pattern analysis
- Public transport integration analysis
- Fleet utilization and parking duration assessment
- Financial modelling and unit economics

## Technologies and Methods

- Python
- Pandas
- GeoPandas
- Matplotlib
- Jupyter Notebook
- Isolation Forest
- Haversine Formula
- Geospatial Analysis
- Data Visualization

## Dataset

The analysis is based on e-scooter trip records containing GPS coordinates, timestamps, vehicle identifiers, and trip information.

Raw datasets are not included in this repository.
